# Text Chat Application - Programming Assignment 1

## Overview

Build a client-server based text chat system using TCP sockets. The server facilitates message relay between multiple clients. All communication is routed through the server. Clients support basic chat features and commands, with functionality verified using `select()` system call — no threading or forking allowed.

---

## Objectives

- Build a TCP-based chat system with:
  - A centralized server
  - Multiple clients
  - Real-time shell command interface
- Maintain message and client state
- Implement logging, output formatting, and communication protocols
